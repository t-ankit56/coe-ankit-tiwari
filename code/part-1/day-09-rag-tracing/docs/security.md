# Security Basics (Fictional Co.)

## Accounts and passwords
All company accounts use single sign-on with a hardware security key or authenticator app. Passwords are never shared, even with the IT team. A password manager is provided and is the only approved place to store credentials.

## Devices
Laptops must have full-disk encryption and an automatic screen lock after 5 minutes. Lost or stolen devices must be reported to the security team within 1 hour, day or night, using the hotline or the security channel.

## Data handling
Customer data must stay in approved systems. It must not be copied to personal drives, email or chat tools. Production data may not be used in test environments unless it has been anonymised.

## Reporting incidents
Anything suspicious, such as a phishing email or an unexpected login alert, is reported to the security team straight away. Reporting a mistake quickly is never punished; hiding one is.
